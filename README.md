# BK - Academic Repository

This repository contains academic materials, course notes, and study resources for my university coursework at BK. It is structured by semester and individual subjects.

## 📚 Course Directory

### Semester 251
- **Analytical Chemistry (`BK_Ana_Chem`)**: Lecture notes, problem sets, and LaTeX sources for chapter summaries.
- **Cell Biology (`BK_CellBiology`)**: Comprehensive study guides, quiz JSONs for Chapters 1-20, and midterm/final term preparation materials.
- **Heat Transfer (`BK_HeatTransfer`)**: Notes and technical documentation.
- **Mass Transfer (`BK_MassTransfer`)**: Principles of mass transfer, distillation, absorption, and related quiz resources.
- **Microbiology (`BK_Microbiology`)**: Materials covering bacterial growth, yeasts, molds, and industrial microbiology applications.
- **Physical and Colloid Chemistry (`BK_Phys_Col_Chem`)**: Detailed LaTeX summaries of thermodynamics, phase equilibrium, and colloid properties.
- **Scientific Socialism (`BK_XHCN`)**: Quiz banks and summaries for socialist theory and history.

### Semester 252
- **Molecular Biology & Inheritance (`BK_MolecularBiology`)**: Notes on genetic mechanisms, transcription, and translation.
- **Communist History (`BK_LSD`)**: Historical reference materials and course outlines.
- **Microbial Fermentation (`BK_Fermentation`)**: Focus on fermenter design and microbial technology.
- **Mechanical Processing Lab Equipment (`BK_MechLabs`)**: Lab reports and equipment documentation.

## 🛠️ Features & Tools
- **Quizzes**: Many courses include structured JSON quiz files (located in `*/quiz/` directories) used for self-assessment.
- **Automation**: Includes Python scripts like `gen_index.py` for repository management and `ai/` tools for quiz generation.
- **LaTeX Documentation**: Several core engineering courses utilize LaTeX for high-quality technical notes.

## 🗂️ Project Structure
```text
BK/
├── ai/                 # AI-assisted study tools & scripts
├── [Course_Folder]/    # Individual course materials
│   ├── quiz/           # JSON quiz files
│   ├── _pdf/           # Reference textbooks and lectures
│   └── Sections/       # LaTeX source files (if applicable)
└── BK.md               # Main index file for Obsidian/Markdown linking
```
