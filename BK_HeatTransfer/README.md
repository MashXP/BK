# BK_HeatTransfer

This repository serves as a comprehensive formula sheet for the Heat Transfer course at Ho Chi Minh City University of Technology (HCMUT). It contains compiled LaTeX documents summarizing key formulas and concepts across various topics.

The main document is `heat_transfer_main.tex`. It includes sections covering:
- Conduction
- Convection
- Heat Exchangers
- Radiation
- Phase Transition
- Refrigeration
- Evaporation
- Boilers and Coolers

## Compilation

To compile the document, you will need a LaTeX distribution (e.g., TeX Live or MiKTeX). Navigate to the root directory of this repository and run the following command:

```bash
pdflatex heat_transfer_main.tex
```

After successful compilation, the comprehensive formula sheet will be available as `heat_transfer_main.pdf`.
