# Microbial Fermentation - Study Materials

This repository contains study materials for the **Microbial Fermentation** course. It includes structured notes, chapter summaries.

## References & Citations

The materials in this repository are based on the following resources:

*   **Lecture Slides:** Assoc. Prof. Dr. Hoang Anh Hoang (HCMUT).
*   **Textbook:** Stanbury, P. F., Whitaker, A., & Hall, S. J. (2017). *Principles of Fermentation Technology* (3rd ed.).
*   **Reference:** Kuila, A., & Sharma, V. (2018). *Principles and Applications of Fermentation Technology*. Scrivener Publishing.

## Directory Structure

*   `BK_Fermentation.md`: The main index and entry point for the study guide.
*   `_study_guide/`: Contains detailed Markdown notes for each chapter.
*   `_quiz/`: Contains files for a my web-based quiz application: https://mashxp.github.io/quiz_webapp/
