# BK_XHCN - Scientific Socialism Study Materials

This repository contains study materials and quizzes related to Scientific Socialism, specifically for the course "Chủ nghĩa xã hội khoa học".

## Structure:
- `_md/`: Markdown files containing study notes and content.
- `quiz/`: Contains files for a my web-based quiz application: https://mashxp.github.io/quiz_webapp/
- `output/`: Generated output files, including compiled questions and OCR revisions.
